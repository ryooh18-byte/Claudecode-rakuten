# おまけ:Claude Codeで楽天の商品検索から紹介文づくりまで自動化する(上級者向け・下書き)

> 【状態:下書き】**★要確認** と書いた箇所は、実際に動かして確かめるまで配布しないこと。
> 根拠は2026年2月の楽天API新仕様についての検索結果の要約のみ(公式ページは未確認)。
> 配布前に、末尾の「配布前チェックリスト」を一度すべて実行する。

## このおまけについて(LPに載せる説明文の案)
LP本体のやり方(商品を自分で選んでClaudeに貼る)で十分に始められます。
このおまけは「もっとラクにしたい」「パソコン操作に抵抗がない」方向けの応用編です。
Claude Codeに楽天の商品検索を任せて、候補の比較から紹介文づくりまでを一気に進めます。
少し難しいので、やってみたい方だけどうぞ。

## できること
- 「50代女性向けのキッチン雑貨、レビューが多い順に10件」と頼むだけで、楽天の商品データを自動で取ってくる
- 取ってきた商品を比べて、おすすめ順に並べる
- 選んだ商品の紹介文(Threads / Instagram用)を書く

## 先に知っておくこと
- 楽天のAPIは2026年2月に新しくなり、旧APIは2026年5月13日に停止の予定(検索結果より)。**★要確認**
- 新APIでは、アプリID・アクセスキーに加えて、**許可されたWebサイト(固定のURL)の登録**と、リクエストに**Referer**を付けることが必要。**★要確認**
- Claudeのチャット画面では、このリクエストを送れない。**パソコンで動くClaude Code**を使う。
- アプリID・アクセスキーは自分専用の鍵。**人に見せない・SNSに載せない・GitHubに公開しない**。

## 準備するもの
1. 楽天会員のアカウント
2. 楽天アフィリエイトの登録(LP本体のSTEP 2)
3. Claude Code(インストール方法はAnthropic公式ドキュメントを見る)
4. 許可するWebサイトのURL(固定のもの)。GitHub Pagesのアドレスなどが使えるか **★要確認**

## 手順

### STEP 1:楽天ウェブサービスでアプリIDとアクセスキーをもらう
1. 楽天ウェブサービスのサイトに楽天IDでログインし、「アプリID発行」を開く
2. アプリ名などを入力する
3. 「許可されたWebサイト」に、準備4のURLを入力する **★要確認(入力欄の名前・形式)**
4. 登録後に表示される「アプリID」と「アクセスキー」を控える **★要確認(画面の表示)**

### STEP 2:鍵を安全にしまう
- プロジェクト用のフォルダを作り、`.env` というファイルに鍵を書く(例:`RAKUTEN_APP_ID=...` `RAKUTEN_ACCESS_KEY=...` `RAKUTEN_REFERER=許可したURL`)
- `.env` はGitHubなどに上げない(`.gitignore` に `.env` を書く)

### STEP 3:商品検索が動くか、先に1回だけ試す
ターミナルで次を実行して、商品データのJSONが返ればOK(`〜`の部分は自分の値)。

```
curl -s "https://openapi.rakuten.co.jp/ichibams/api/IchibaItem/Search/20220601?applicationId=〜&accessKey=〜&keyword=キッチン雑貨&hits=5&sort=-reviewCount&format=json" -H "Referer: 許可したURL"
```
**★要確認**:エンドポイント、パラメータ名(`sort=-reviewCount` など)、返ってくる項目

エラーが出たとき(検索結果より。**★要確認**)
- 403で「REFERRER_MISSING」→ Refererが付いていない
- 400 → アプリIDかアクセスキーが足りない、または旧IDを使っている
- 許可されていないURLを使っている

### STEP 4:Claude Codeに任せる
プロジェクトのフォルダでClaude Codeを起動して、次のように頼む。

> `.env` の鍵を使って、楽天市場の商品検索API(上のcurlと同じ形式。Refererも付ける)で
> 「50代女性向けのキッチン雑貨」をレビュー数の多い順に10件探してください。
> 商品名・価格・レビュー数・レビュー平均・商品URLを表にして、
> おすすめの上位3つを理由つきで選び、1位の商品のThreads用の紹介文(末尾に #PR)を書いてください。

### STEP 5:リンクと報酬のひもづけを確認する
- 取ってきた商品URLに、アフィリエイト用の情報(rafcid)が自動で付くと言われている **★要確認**
- 必ず1回、そのリンクをクリックして、楽天アフィリエイト管理画面のクリック数に反映されるか確かめる
- 反映されないときは、管理画面で作った紹介リンクを使う(LP本体のSTEP 3の方法)

### STEP 6:投稿する
リンクを載せる投稿には「#PR」を付ける(LP本体のSTEP 5と同じ)。
