# リール動画の台本(1分以内)

> 方針:台本はシンプルに伝えて、詳しい説明はLPで行う。
> 話す文字数の目安は、1分で約300字。CTAの分(約8〜10秒)を残して、本編は200字前後にする。

## 共通キーワード(LPとそろえる)
- タイトル:Claudeに任せる楽天アフィリエイト はじめの準備ガイド
- 手順の数:5ステップ

## 台本

| 秒数の目安 | 話す内容 | テロップ案 |
|---|---|---|
| 0〜5秒(フック) | 楽天アフィリエイト、商品を探すだけで1日が終わっていませんか? | 商品探しだけで1日が終わる… |
| 5〜12秒(共感) | 紹介文が思いつかなくて、投稿も続かない…。 | 紹介文が思いつかない… |
| 12〜22秒(解決) | 実はそれ、Claudeに任せられます。商品の比較も、紹介文づくりも、ぐっとラクになります。 | Claudeに任せられます |
| 22〜45秒(手順) | 準備はたったの5ステップ。まず、楽天アフィリエイトに登録。次に、商品を選んでリンクを作ります。その商品の情報をClaudeに貼って、紹介文を作ってもらい、最後に「PR」を付けて投稿するだけ。 | 5ステップ ①準備 ②登録 ③商品とリンク ④Claudeで紹介文 ⑤#PRで投稿 |
| 45〜50秒(安心) | パソコンが得意じゃない私でもできました。 | 私でもできました |
| 50〜58秒(CTA) | 【CTA:あとで入れる】 | 【CTA:あとで入れる】 |

## 通して読む用(CTA以外)
楽天アフィリエイト、商品を探すだけで1日が終わっていませんか?
紹介文が思いつかなくて、投稿も続かない…。
実はそれ、Claudeに任せられます。商品の比較も、紹介文づくりも、ぐっとラクになります。
準備はたったの5ステップ。まず、楽天アフィリエイトに登録。次に、商品を選んでリンクを作ります。その商品の情報をClaudeに貼って、紹介文を作ってもらい、最後に「PR」を付けて投稿するだけ。
パソコンが得意じゃない私でもできました。

## メモ
- CTAの文言と、LPへの導線(LINE・プロフィールのリンクなど)は、くみが別に作って入れる。
- 「PR」は、LPのSTEP 5(#PRを付ける)と同じ内容。
- 成果を約束する言い方(「必ず稼げる」など)は入れない。
